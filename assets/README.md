# Visual assets

These files are installed by Home Manager under
`~/.local/share/dotfiles/assets` so the desktop does not depend on files from
`~/Pictures`.

## Inventory

- `icons/nixos.svg`: NixOS logo used by Waybar.
- `wallpapers/purple-neon-lights.jpg`: Hyprlock background.
- `wallpapers/magical-mystical-landscape.jpg`: Hyprpaper wallpaper.
- `photos/lockscreen-profile.jpg`: personal lock-screen profile image.

JPEG EXIF, XMP, IPTC, comment, and location metadata were removed before the
files were added here. Redistribution terms for third-party artwork should be
verified before making this repository public. The profile photograph is
personal and should only be published intentionally.
